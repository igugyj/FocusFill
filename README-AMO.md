# FocusFill — AMO Build Instructions

## Environment

- OS: Ubuntu 24.04 (AMO default reviewer environment)
- Node.js: 22.x or later (tested with v22.22.2)
- npm: 10.x or later (bundled with Node.js)

No environment variables, API keys, or network access are required to build.

## Build Steps

Run the following commands from the root of the source package:

1. npm install
2. npm run build:firefox

The unpacked extension will be generated at: `.output/firefox-mv3/`

To generate the exact zip submitted to AMO: 3. npm run zip

The zip file will be created at `.output/focusfill-<version>-firefox.zip`.

## Notes

- `npm install` automatically runs `wxt prepare` via the `postinstall` script. This generates the `.wxt/` directory required for TypeScript compilation. Do not use `--ignore-scripts`.
- The build uses WXT 0.21 and Vite 8. All dependencies are installed from the official npm registry.
- `@wxt-dev/auto-icons` generates the extension icons at build time from `assets/icon.png`. This is expected and part of the build process.
- The source package does not include `node_modules/`, `.output/`, or `.wxt/`. These are regenerated by the steps above.

## Source Code Structure

- `entrypoints/` — Extension entrypoints (content script, background, settings page)
- `utils/` — Shared logic (matcher, fill, highlight, storage, undo)
- `wxt.config.ts` — Manifest and build configuration
- `package.json` / `package-lock.json` — Dependency definitions (lockfile included for reproducible installs)
